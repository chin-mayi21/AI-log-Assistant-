# AI Log Assistant datasets

The AI core now indexes the deployment/DevOps troubleshooting corpus:

- [`deployment_logs.json`](./deployment_logs.json) — 400 structured synthetic training records.
- [`deployment_logs.csv`](./deployment_logs.csv) — CSV version of the same records.
- [`test_cases.json`](./test_cases.json) — 24 held-out deployment troubleshooting test cases.
- [`build_deployment_dataset.py`](./build_deployment_dataset.py) — reproducible dataset builder.
- [`evaluation_results.json`](./evaluation_results.json) — generated by the full local evaluation.

Dataset schema, categories, severity, and evaluation semantics are documented in
[`../docs/dataset.md`](../docs/dataset.md).

The earlier generic application-log exercise remains available as `log_dataset.json`,
`log_dataset.csv`, and `test_queries.json` for historical reference. It is **not** ingested by the
deployment RAG collection.
